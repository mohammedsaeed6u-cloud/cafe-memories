# أمور مؤجلة قبل إطلاق عام

هذه قائمة احتياجات معلنة **وليست وعودًا بمواعيد**:

- تجربة شاملة في staging مع Supabase Auth/Storage حقيقيين ومعالجة هجرة البيانات القديمة والنسخ الاحتياطي والتراجع.
- حدود معدل طلبات موثوقة عند الحافة، اختبار التزامن على اتصالات مستقلة، ومراقبة الأخطاء والأداء.
- استرجاع حساب الضيف أو تحويله لهوية دائمة، ومراجعة قانونية للخصوصية وطلبات حذف البيانات/الصور والنسخ الاحتياطية.
- دعوات موظفين ومراجعة صلاحيات الأدوار، واجهة إعداد قواعد ولاء أكثر مرونة، وتحسين تجربة استقبال ضيف جديد.
- تطوير توصيل طابعة فرع فعلية أو جهاز فوتوبوث مستقل فقط بعد تحديد العتاد، وتفويض الضيف لنقل الصورة إلى الموظف، وسياسة حذف النسخ المطبوعة؛ المتاح الآن تصميم فوتوبوث رقمي وطباعة/PDF يدويًا من حساب الضيف. تُدرس Wallet والفوترة مستقبلًا ببنية أمان منفصلة، لا بإعادة استخدام النماذج المحلية القديمة.

صفحة [المنتج](PRODUCT.md) توضح المتاح فعلًا، و[دليل النشر](DEPLOYMENT_AND_DATA_MIGRATION.md) يوضح المخاطر والتجارب المطلوبة.
