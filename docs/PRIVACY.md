# الخصوصية — مصدر الحقيقة

راجع [صفحة الخصوصية الحية](../src/app/privacy/page.tsx) وتفاصيل الموافقة والتخزين في [دليل التشغيل](DEPLOYMENT_AND_DATA_MIGRATION.md). مستندات الخصوصية القديمة التي تحدثت عن جمع أرقام هاتف إلزامية أو محفظة إلكترونية أو حذف آلي لم تكن تمثل التطبيق الحالي. يلزم اعتماد سياسة قانونية وعمليات حذف/احتفاظ بالبيانات قبل إطلاق تجاري عام.
