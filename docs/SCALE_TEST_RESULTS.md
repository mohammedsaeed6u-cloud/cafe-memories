# حالة قياسات الأداء

النتائج المنشورة سابقًا في هذه الصفحة كانت **أهدافًا افتراضية وليست قياسات**. لا توجد نتيجة حمل قابلة لإعادة الإنتاج للنسخة الحالية، لذا أُزيلت الأرقام غير المسندة والسكربتات الاصطناعية التي كانت تطلب `/api/health` فقط. لا ينبغي ادعاء سعة 5,000 RPS أو WebSockets أو مليون مستخدم بناءً عليها.

قبل إعلان أي قدرة استيعاب، اختبر رحلة حقيقية في staging (تسجيل ضيف، رفع صورة، تأكيد زيارة، صرف، Feed الشاشة) ببيانات معزولة ومراقبة أخطاء قاعدة البيانات وStorage وذاكرة الخادم والكمون p95/p99 وحدود الاستضافة. انظر [دليل النشر](DEPLOYMENT_AND_DATA_MIGRATION.md).
