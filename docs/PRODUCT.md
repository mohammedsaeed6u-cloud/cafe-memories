# ما يمكن استخدامه الآن

1. إنشاء حساب منشأة بالبريد وكلمة المرور، تأكيده، ثم إنشاء منشأة وفرع مالك تلقائيًا؛ أو Google OAuth إذا أعدّه مسؤول المشروع.
2. توليد QR للفرع في لوحة المنشأة. الضيف يفتحه ليبدأ جلسة Supabase مجهولة خاصة بالمتصفح، ويرى زياراته الحقيقية ويستطيع رفع صورة مع خيار عرضها على شاشة الفرع (الافتراضي خاص).
3. الموظف ذو العضوية المصرح بها يؤكد عملية الشراء لضيف حضر إلى ذلك الفرع في الساعتين الأخيرتين. يمكنه صرف مكافأة عند بلوغ عدد الزيارات المؤكدة.
4. إدارة مراجعة الصور، وإقران شاشة فرع برمز قصير؛ الشاشة تعرض الصور المعتمدة وبموافقة الضيف، ويمكن فصلها أو سحب الموافقة.

الشاشات تبيّن حالات التحميل والفراغ/الأخطاء بدل بيانات تجريبية. لا يتوفر في المنتج الحالي تصوير فوتوبوث بشريط/ملصقات، دفع أو فواتير، محفظة Apple/Google مُوقّعة، طباعة فعلية، أو نشر صور عامة. يتطلب عمل الحسابات مشروع Supabase مضبوطًا عبر متغيرات البيئة؛ لا تُنشأ حسابات محلية افتراضية.
