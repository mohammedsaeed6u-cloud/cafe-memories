# البنية الحالية — Café Memories

- **الواجهة:** Next.js 16 App Router وReact 19، شاشات: الرئيسية، تسجيل المنشأة، لوحة الإدارة، محطة الموظف، صفحة الضيف، شاشة الصالة، إدارة المنصة، الخصوصية والشروط. لا توجد بيانات تجريبية تُعرض في هذه المسارات.
- **الحسابات:** Supabase Auth بالبريد/كلمة المرور أو Google للمنشأة؛ عند تأكيد حساب البريد تنشأ المنشأة والفرع وعضوية المالك في معاملة SQL؛ مستخدم Google جديد يختار اسم المنشأة ورابطها بعد OAuth ثم تُنشأ بمعاملة SQL نفسها. ضيف المنشأة يستخدم جلسة Supabase مجهولة موثّقة ويسجل طلب حضور لفرع محدد لفترة قصيرة؛ فتح الرابط لا يثبت وجوده الفعلي. لا يوجد دخول موظف عبر PIN محلي؛ عضويته تحتاج إجراء إداري معتمد.
- **البيانات:** PostgreSQL من خلال Supabase. RLS يحمي استعلامات المستخدم المباشرة، وRoutes تتحقق من هوية المستخدم والعضوية والفرع قبل أي استخدام لمفتاح `service_role`. الترحيلات في `supabase/migrations/00001` ثم `00002` ثم `00003` ثم `00004` لإعدادات حساب الضيف الخاصة ثم `00005` لسجل كروت الزيارات والصور المؤكدة.
- **المعاملات:** ترحيل `00003` يوفّر RPC لتسجيل الزيارة المؤكدة وصرف المكافأة ومنح موافقة عرض الصورة واقتران الشاشة وإنشاء المنشأة. عمليات التسجيل/الصرف تقفل الصفوف أو تستخدم advisory locks ومفاتيح idempotency.
- **الصور والكروت:** معالجة WebP بواسطة `sharp` على خادم Node، وحفظ الملفات في bucket خاص. بعد ختم موثّق، يربط RPC بصلاحية الخادم صورة ضيف واحدة بزيارة موثّقة تحت قفل قاعدة البيانات؛ لا ينشئ الرفع زيارة جديدة. `keepsake_cards` يجمّد قائمة الزيارات واسم المكافأة عند بلوغ العتبة عبر trigger، حتى لو تغيّرت القاعدة؛ trigger الصرف يربط أقدم كارت مؤهل بحدث الهدية. مسار `/api/v1/customer/story` يفحص جلسة الضيف ويربط طلبات الكروت والصور بملكيته والمنشأة، ولا يفتح الملفات للعموم؛ رابط `/api/v1/media/[memoryId]` يفحص الملكية أو عضوية التاجر أو رمز الشاشة + موافقة الضيف في كل طلب. يطبع الضيف بنفسه تصميم A6 من المتصفح، دون اتصال آلي بطابعة. لا تُظهر الشاشة إلا صورًا معتمدة في فرعها، وتستطلع البيانات كل 15 ثانية.

لم تُختبر الترحيلات على مشروع Supabase مباشر بعد. لا WebSocket أو اشتراكات مدفوعة أو محفظة رقمية مُوقّعة أو ربط مباشر بطابعة في النسخة الحالية؛ حفظ PDF/طباعة المتصفح يدويًا متاح للضيف. دليل النشر والتجربة على staging في [DEPLOYMENT_AND_DATA_MIGRATION.md](DEPLOYMENT_AND_DATA_MIGRATION.md).
