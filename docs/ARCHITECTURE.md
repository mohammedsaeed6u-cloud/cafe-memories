# البنية الحالية — Café Memories

- **الواجهة:** Next.js 16 App Router وReact 19، شاشات: الرئيسية، تسجيل المنشأة، لوحة الإدارة، محطة الموظف، صفحة الضيف، شاشة الصالة، إدارة المنصة، الخصوصية والشروط. لا توجد بيانات تجريبية تُعرض في هذه المسارات.
- **الحسابات:** Supabase Auth بالبريد/كلمة المرور أو Google للمنشأة؛ عند تأكيد الحساب تنشأ المنشأة والفرع وعضوية المالك في معاملة SQL. ضيف المنشأة يستخدم جلسة Supabase مجهولة موثّقة، ويحضر إلى فرع محدد لفترة قصيرة. لا يوجد دخول موظف عبر PIN محلي؛ عضويته تحتاج إجراء إداري معتمد.
- **البيانات:** PostgreSQL من خلال Supabase. RLS يحمي استعلامات المستخدم المباشرة، وRoutes تتحقق من هوية المستخدم والعضوية والفرع قبل أي استخدام لمفتاح `service_role`. الترحيلات في `supabase/migrations/00001` ثم `00002` ثم `00003`.
- **المعاملات:** ترحيل `00003` يوفّر RPC لتسجيل الزيارة المؤكدة وصرف المكافأة ومنح موافقة عرض الصورة واقتران الشاشة وإنشاء المنشأة. عمليات التسجيل/الصرف تقفل الصفوف أو تستخدم advisory locks ومفاتيح idempotency.
- **الصور:** معالجة WebP بواسطة `sharp` على خادم Node، وحفظ الملفات في bucket خاص. رابط `/api/v1/media/[memoryId]` يفحص الملكية أو عضوية التاجر أو رمز الشاشة + موافقة الضيف في كل طلب. لا تُظهر الشاشة إلا صورًا معتمدة في فرعها، وتستطلع البيانات كل 15 ثانية.

لم تُختبر الترحيلات على مشروع Supabase مباشر بعد. لا WebSocket أو اشتراكات مدفوعة أو محفظة رقمية مُوقّعة أو طباعة فعلية في النسخة الحالية. دليل النشر والتجربة على staging في [DEPLOYMENT_AND_DATA_MIGRATION.md](DEPLOYMENT_AND_DATA_MIGRATION.md).
